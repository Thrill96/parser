Panel 1 — Foundation: Claude Basics & Models
What Claude Is

Definition: a family of large language models that read, write, code, and reason over very long text and images.

Models — Opus = most capable; Sonnet = balances speed + smarts; Haiku = fastest & cheapest.

Inputs — text + images, very long context (hundreds of pages), many languages.

Access — Claude.ai (chat + Projects + Artifacts) · Claude Code (repos) · API (SDKs).

Core Concepts & Terms

Context window: all the text + images Claude can hold at once — very long (hundreds of pages on top models).

System instructions: standing directions that set role, tone & rules for the whole chat.

Projects: persistent workspaces storing docs, instructions & chats — long-term memory.

Artifacts: a live side panel where Claude renders editable code, docs, tables & UIs.

Talking to Claude Well

Always give 4 parts —

  1. ROLE
    1. "You are a [expert/coach/dev]…"
  2. GOAL
    1. one clear objective
  3. INPUT
    1. paste/upload all context
  4. OUTPUT FORMAT
    1. "5 bullets + summary + table"

Ask-then-answer — "Ask up to 5 questions first, then propose a plan and execute." — cuts hallucinations.

Constraints — "≤200 words", "6th-grade level", "no jargon".

Partner, not vending machine — iterate: "v2: calmer tone, more numbers." Save winners to a library/Project.

Prompt Patterns That Pay Off

Rewrite — "Rewrite for [audience] in [tone]; keep facts, cut filler, 3–5 bullets on top."

Critique-then-improve — "Critique this as a tough editor, then rewrite fixing every issue."

Compare — "Compare A vs B for [goal]: pros/cons table + a recommendation."

Checklist & SOP — "Turn this process into a 10-step checklist + a full SOP (who/what/when)."

Scenario recipe — "Give 5 prompt recipes for [use case]: Scenario, Goal, Template, Example."

Guardrails & Safety

If-unsure clause — "If you're not confident or data may be stale, say what you're unsure about & what you'd need."

Source-aware — "Answer only from these documents unless you clearly label outside knowledge."

Sensitive topics — health/legal/finance: treat Claude as a drafting aid only — route final calls through a pro.

Private data — strip PII, card & bank details before pasting.

Panel 2 — Claude.ai, Projects & Artifacts
Claude.ai — The Interface

What you see — chat pane (Sonnet/Opus/Haiku) · sidebar of Projects + history · Artifacts side panel.

Chats vs Projects — chats for ad-hoc; Projects for anything recurring, multi-doc, or team-based.

Projects — Your Cowork Space

What they are — named workspaces grouping instructions, uploaded docs & chats; their own long-context memory.

When to use — client folders · a course/product build · an SOP library · a research theme.

Setup template —

  1. Name it ("SMB AI Ops — Marketing & Ops").
  2. Add docs: best emails, pages, offers, style guide, ICP.
  3. Instructions: "You are our in-house strategist; brand voice friendly + practical; audience SMB owners $500K–$5M."
  4. Default model: Sonnet 4.6; Opus 4.7 for deep work.

Project prompts — "From these files, write a 1-page brief of our offers, ICP & positioning + 10 content ideas."

Artifacts — Live Workspace

What they are — a panel rendering code, docs, tables, UIs as a live, editable preview; can persist & call tools.

When to use — building code · designing pages/templates · dashboards & small reusable tools.

Workflow — "Create an Artifact that does X" → edit inline / ask for changes → export or share.

Examples — a prompt-library page · an SOP generator form · an AI content calendar table.

Everyday Prompt Recipes

Email/comms — "Turn this thread into a decision summary, a client email, and a 5-bullet internal recap."

Meetings — before: 5 questions + 3 risks. after: decisions, action items (owner+due), open questions.

Repurpose — "From this article: 3 LinkedIn posts, 3 email teasers, a 10-slide outline."

Decisions — "As a skeptical advisor, challenge this plan: assumptions, failure modes, early warning signs."

Panel 3 — Claude Code & Cowork Workflows
Claude Code — What It Is

Definition: a coding-focused Claude wired to your files, repos & terminal to read, edit & generate code in context.

Excels at — repo-wide refactors, onboarding to a codebase, multi-file changes guided by a plan.

Core Capabilities

Understand — explain files/architecture; "where is X?", "what breaks if I change Y?"

Refactor & build — multi-file changes with tests; migrations, endpoints, docs.

DevOps — shell scripts, CI configs, IaC, deploy scripts.

Agentic — run repeatable playbooks/checklists for complex refactors.

Code Prompt Patterns

Repo map — "Summarize architecture, key modules, data models & riskiest areas to change."

Plan-then-patch — 1) propose a plan (files + tests). 2) implement steps 1–3, diffs only, stop before destructive changes.

Guardrails — "Explain changes, keep them minimal, preserve style, add tests, ask before destructive commands."

Review mode — "As a senior engineer, review this diff: correctness, readability, perf, security, tests."

Cowork Style — Claude + Your Stack

Version control — "Summarize these commits as a PR description with risks + testing notes."

CI/CD — "Propose a pipeline (lint, test, build, staging deploy) for our stack; debug this failing job."

Non-dev teammates — Artifacts so staff trigger workflows: paste ticket → drafted reply; paste CSV → cleaned + flagged.

SMB Recipes

Owner brief — "From this P&L + notes: 1-page brief (what changed, why, watch), 3 questions for my accountant, 3 team actions."

Client summary — "From these transcripts: status, open promises (owner+due), risks, next 3 moves."

Template builder — "Turn this email into a template with marked variables + 3 industry examples."

SOP upkeep — "Compare legacy SOPs to the new doc: redline, one master SOP, list outdated references."
