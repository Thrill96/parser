# Cheat Sheet Topics Queue

Drop a topic in the table below and run `/cheatsheet <topic name>` (or just say "build the next queued topic").
The pipeline auto-researches → writes deep content (`NN-slug.md`) → **stops for your approval** → renders the cards.

## How to add a topic
Fill one row. Only **Topic** is required; the rest sharpen the output.
- **Tier:** `free` (consumer lead magnet, 3 levels) or `paid` (practitioner guide, dual-lens).
- **Audience:** who it's for + expertise vantage (e.g., "$10M owner-operator", "15-yr contracts attorney").
- **Panels:** default 3. Free = Beginner/Intermediate/Advanced. Paid = Foundation/Workflow/Playbook.
- **Sources/notes:** books, articles, your POV/hot-takes, client numbers to weave in.
- **Status:** `queued` → `drafted` → `approved` → `rendered`.
